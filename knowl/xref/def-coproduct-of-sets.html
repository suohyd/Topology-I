Definition 1.1.7. (Coproduct/disjoint union of sets).

Let \(I\) be a nonempty indexing set, and let \(X_\alpha\) be sets for each \(\alpha\in I\text{.}\) A coproduct or a disjoint union of \(X_\alpha\)’s is the set \(\coprod X_\alpha\) with the following properties.
  1. For each \(\alpha\in I\text{,}\) there is a map \(i_\alpha\colon X_\alpha\to\coprod X_\alpha\text{.}\)
  2. If \(Y\) is any set together with maps \(f_\alpha\colon X_\alpha\to Y\) for each \(\alpha\in I\text{,}\) then there exists a unique map \(g\colon\coprod X_\alpha\to Y\) such that \(f_\alpha=g\circ i_\alpha\) for each \(\alpha\in I\text{,}\) see the following diagram.
