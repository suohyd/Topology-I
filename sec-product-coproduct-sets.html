    Section 1.1 Product and coproduct of sets

    We begin with the definition of product of sets.

    Definition 1.1.1. (Product of sets).

    Let \(I\) be a nonempty set and consider sets \(X_\alpha\) for every \(\alpha\in I\text{.}\) The product of \(X_\alpha\) is a set denoted by \(\prod X_\alpha\) and it is `characterized’ by the following properties.
    1. For each \(\alpha\in I\text{,}\) there is a map \(\pi_\alpha\colon\prod X_\alpha\to X_\alpha\)
    2. If \(Y\) is any set together with maps \(f_\alpha\colon Y\to X_\alpha\) for each \(\alpha\text{,}\) then there is a unique map \(g\colon Y\to\prod X_\alpha\) satisfying \(\pi_\alpha\circ g=f_\alpha\text{.}\)
    These conditions can be summarize in the following `diagram’.

    Lemma 1.1.3. (Existence of the product of sets).

    The product of sets \(X_\alpha\) is the Cartesian product of sets, i.e.,
    \begin{equation*} \prod X_\alpha=\lbrace(x_\alpha)_{\alpha\in I}:x_\alpha\in X_\alpha\rbrace. \end{equation*}

    Proof.

    We let \(X=\{(x_\alpha)_{\alpha\in I}:x_\alpha\in X_\alpha\}\text{.}\) We consider, for each \(\beta\in I\text{,}\) the projection onto \(\beta\)-th component of \(X\text{,}\) i.e., \(\pi_\alpha\colon X\to X_\beta\) by \((x_\alpha)\mapsto x_\beta\text{.}\)
    Let \(Y\) be a set with maps \(f_\alpha\colon Y\to X_\alpha\) for each \(\alpha\in I\text{.}\) A map \(g\colon Y\to X\) satisfying \(f_\alpha=\pi_\alpha\circ g\) must map an element \(y\in Y\) to \((f_\alpha(y))_{\alpha\in I}\in X\text{.}\) Hence, we get the result.

    Checkpoint 1.1.4.

    Find the product of \(\{1,2\}\) and \(\{1,2\}\text{.}\) Also find the product of \(\R\) and \(\Z\text{.}\)

    Lemma 1.1.5. (Uniqueness of product of sets).

    The product of sets is unique up to a canonical bijection of sets.

    Proof.

    Proof is left as an exercise.

    Remark 1.1.6.

    Lemma 1.1.5 makes precise the meaning of the word characterized in Definition 1.1.1.
    We now define the “coproduct” of sets.

    Definition 1.1.7. (Coproduct/disjoint union of sets).

    Let \(I\) be a nonempty indexing set, and let \(X_\alpha\) be sets for each \(\alpha\in I\text{.}\) The coproduct or the disjoint union of \(X_\alpha\)’s is the set \(\coprod X_\alpha\) with the following properties.
    1. For each \(\alpha\in I\text{,}\) there is a map \(i_\alpha\colon X_\alpha\to\coprod X_\alpha\text{.}\)
    2. If \(Y\) is any set together with maps \(f_\alpha\colon X_\alpha\to Y\) for each \(\alpha\in I\text{,}\) then there exists a unique map \(g\colon\coprod X_\alpha\to Y\) such that \(f_\alpha=g\circ i_\alpha\) for each \(\alpha\in I\text{,}\) see the following diagram.
